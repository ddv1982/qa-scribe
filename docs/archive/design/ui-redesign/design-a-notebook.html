Summary

After retrying a declined payment, the error message disappears while the payment remains incomplete.

Steps to reproduce

  1. Open checkout with an item in the cart.
  2. Submit a card that returns a decline.
  3. Select Retry without changing the card.

Expected result

The error stays visible and explains how to resolve it.

Actual result

The error clears and the order stays pending with no feedback.
